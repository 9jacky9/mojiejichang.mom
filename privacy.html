隐私政策 (Privacy Policy)

我们视用户的隐私为至高无上的准则，公开透明阐述我们的零日志保障体系。

1. 严正声明：绝对零用户活动日志保留（Zero Activity Logs）

魔戒机场自成立第一天起，便确立了“绝不记录、绝不存储、绝不追踪任何用户网络活动数据”的无妥协原则。

在技术实现层面，无论在任何场景下，我们均严格不保留以下任何活动信息：

  • 无浏览足迹记录：不记录您在互联网上访问的任何网站网址（URL）、浏览的内容网页或网络交互。
  • 无用户原始 IP 映射记录：不记录您连接服务器时的真实公网 IP 地址，亦不保留客户端与出口 IP 之间的映射表。
  • 无 DNS 请求留存：所有域名解析请求直接在加密专网内存中完成，不落地写入磁盘，解析完毕后内存瞬时释放。
  • 无通信数据包检查：不进行任何深度包检测（DPI），传输内容经过端到端加密，即便平台自身亦无法查看明文。

2. 纯内存化（RAM-Only）服务器无痕运行

魔戒机场所有节点网关服务器均运行在定制化的轻量只读内存操作系统中，所有磁盘日志功能均被物理级关闭。数据仅在高速易失性 RAM 中完成路由转发。一旦服务器发生重启或断电，内存中存在的任何临时运行变量将立刻荡然无存，杜绝任何物理层面的数据截获与泄露隐患。

3. 最小化数据收集原则

为了保障账单服务的顺利流转与套餐计费核销，我们仅维护最基本的必要账户信息：

  • 注册与认证信息：仅用于登录验证的加密电子邮箱地址以及经散列算法（Argon2/Bcrypt）加盐加密的密码字符串。
  • 总流量使用统计：仅统计用户当前计费周期内已消耗的总体流量数值（如：已使用 60GB / 380GB），用以判定是否达到套餐限额，该统计完全剥离任何访问目标信息。

4. 现代军工级端到端加密

客户端与服务器之间的每一路通信均强制启用现代密码学最高标准的对称与非对称算法（包含 TLS 1.3、ChaCha20-IETF-Poly1305 及 AES-256-GCM 密文套件）。确保即便在未受信任的公共无线网络（如咖啡厅 Wi-Fi、机场公用网络）环境下，通信亦坚不可摧。

5. 拒绝第三方商业共享与数据贩卖

魔戒机场的商业模式纯粹依赖于优质专线订阅服务费，我们从不、且永远不会将任何用户信息或流量元数据向第三方商业营销机构或广告商出售、出租或分享。
